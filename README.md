# Team Signature Forge
Live page: https://aamirtechs.github.io/team-signature-forge/

Upload a staff CSV and download a ZIP of identical on-brand HTML email signatures, one file per person, with install instructions for Gmail, Outlook and Apple Mail. It runs entirely in the browser so files and text you paste stay on your device. Built for busy operators who need a correct answer and a downloadable file, not another account.

## Features
- Template picker with 3 table-based Outlook and Gmail safe layouts
- Staff CSV mapping for name, title, phone, email and department
- Preview per person before download
- ZIP of HTML files named by employee plus a README install guide
- Optional disclaimer and banner row, brand colours and logo URL

## How it works
Add your input in the tool card, choose the options, and run the tool. Processing happens locally in src/logic.js and the page wiring. You can review the results on screen and download the output file.

## Privacy
Runs 100% in your browser. Your files never leave this device, nothing is uploaded,
and there is no tracking.

## Development
Core logic lives in `src/logic.js` and is shared by the page and the tests.
Run the tests with `npm test`.
